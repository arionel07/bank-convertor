Если счёт вашей компании открыт в **Moldindconbank (MICB)** и учёт ведётся
в 1С, знакомая ситуация: выписка приходит как PDF, а 1С не умеет читать
такой файл напрямую — приходится вручную создавать платёжные документы по
каждой строке.

**bank-converter** убирает именно этот шаг: вы загружаете PDF-выписку
Moldindconbank, проверяете транзакции в редактируемой таблице и сразу
экспортируете в формат, который 1С понимает без дополнительных
настроек — **1CClientBankExchange**.

## Что понадобится

- Выписка по счёту Moldindconbank в формате PDF, скачанная из
  **MICB Web Banking**
- Доступ к базе 1С, где вы ведёте учёт платежей
- Пара минут — регистрация не обязательна для первой конвертации

## Шаг 1 — Скачайте выписку из MICB Web Banking

В личном кабинете **MICB Web Banking** (или MICB Business — для
юридических лиц) откройте раздел выписок по счёту, выберите нужный период
и сформируйте файл в формате **PDF**.

## Шаг 2 — Загрузите PDF в bank-converter

Откройте [конвертер](/converter) и перетащите файл в область загрузки.
Приложение автоматически распознаёт дату, контрагента, назначение платежа
и сумму каждой операции, включая отдельные колонки **Дебет/Кредит**,
типичные для выписки Moldindconbank.

## Шаг 3 — Проверьте и поправьте транзакции

Автоматическое распознавание работает быстро, но стоит сверить результат —
особенно если описание операции переносится на несколько строк. Таблица
предпросмотра полностью редактируема: можно исправить любую ячейку прямо
на странице, до экспорта.

## Шаг 4 — Экспортируйте в 1С (TXT)

Нажмите **Экспорт 1C (TXT)**. Файл собирается по формату
1CClientBankExchange версии 1.02: для каждой операции формируется секция
`СекцияДокумент=Платежное поручение`, контрагент записывается на верную
сторону (плательщик для поступлений, получатель для списаний), а сам файл
сохраняется в кодировке **windows-1251**.

## Шаг 5 — Загрузите файл в 1С

В 1С откройте журнал банковских выписок и выберите **«Загрузить из файла
обмена»**, затем укажите скачанный TXT-файл. Платёжные документы
создадутся автоматически — с уже заполненными суммами, контрагентом и
назначением платежа.

## Лимиты и апгрейд

Без регистрации доступна одна бесплатная конвертация. С бесплатным
аккаунтом — **2 выписки в месяц**. Если выписок больше, тариф **Pro**
снимает лимит — смотрите [тарифы](/price).
