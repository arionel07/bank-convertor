Если вы ведёте учёт в 1С и ежемесячно скачиваете выписку по расчётному
счёту из **Сбербанк Бизнес Онлайн** в виде PDF, знакомая ситуация: 1С не
умеет читать такой файл напрямую. Приходится открывать выписку, смотреть
на каждую строку и вручную создавать платёжные документы — долго и легко
ошибиться в сумме.

**bank-converter** убирает именно этот шаг: вы загружаете PDF-выписку
Сбербанка, проверяете транзакции в редактируемой таблице и сразу
экспортируете в формат, который 1С понимает без дополнительных
настроек — **1CClientBankExchange**.

## Что понадобится

- Выписка по счёту Сбербанка в формате PDF, скачанная из СберБизнес
- Доступ к базе 1С, где вы ведёте учёт платежей
- Пара минут — регистрация не обязательна для первой конвертации

## Шаг 1 — Скачайте выписку из СберБизнес

В личном кабинете СберБизнес (или Сбербанк Бизнес Онлайн) откройте раздел
выписок по счёту, выберите нужный период и скачайте файл в формате
**PDF**. Экспорт в другие форматы не нужен — bank-converter читает текст
прямо из PDF-файла.

## Шаг 2 — Загрузите PDF в bank-converter

Откройте [конвертер](/converter) и перетащите файл в область загрузки —
или нажмите, чтобы выбрать его вручную. Первую выписку можно обработать
без регистрации. Приложение автоматически распознаёт дату, назначение
платежа и сумму каждой операции, включая типичный для Сбербанка формат
«дебет / кредит / остаток» с датами в формате ДД.ММ.ГГГГ.

## Шаг 3 — Проверьте и поправьте транзакции

Автоматическое распознавание работает быстро, но стоит сверить результат —
особенно если в выписке встречаются нестандартные формулировки назначения
платежа. Таблица предпросмотра полностью редактируема: можно исправить
любую ячейку (дату, описание, сумму, валюту) прямо на странице, до
экспорта.

## Шаг 4 — Экспортируйте в 1С (TXT)

Нажмите **Экспорт 1С (TXT)**. Файл собирается по формату
1CClientBankExchange версии 1.02: для каждой операции формируется секция
`СекцияДокумент=Платежное поручение`, а сам файл сохраняется в кодировке
**windows-1251** — именно так, как 1С ожидает при загрузке.

## Шаг 5 — Загрузите файл в 1С

В 1С откройте журнал банковских выписок (или документов «Платёжное
поручение») и выберите **«Загрузить»** / **«Загрузить из файла обмена»**,
затем укажите скачанный TXT-файл. Платёжные документы создадутся
автоматически — с уже заполненными суммами и назначением платежа,
останется только распределить их по счетам учёта.

## Лимиты и апгрейд

Без регистрации доступна одна бесплатная конвертация — чтобы быстро
оценить результат. С бесплатным аккаунтом — **2 выписки в месяц**. Если
выписок больше, тариф **Pro** снимает лимит — смотрите
[тарифы](/price).
