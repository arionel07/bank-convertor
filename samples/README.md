# samples

Пример PDF-выписок для калибровки парсеров в `src/lib/parsers/`.

`maib.pdf` здесь ожидается, но отсутствует — `src/lib/parsers/maib.ts` был
написан по типовому макету молдавских банковских выписок (дата → описание →
дебет/кредит/сальдо), без калибровки по реальному файлу. Перед продакшеном:

1. Положите реальный `maib.pdf` (без персональных данных клиента, только для
   разработки) в эту папку.
2. Прогоните его через `extractPdfText()` (`src/lib/pdf/extract-text.ts`) и
   посмотрите на построчный вывод.
3. Сверьте `DATE_RE` / `AMOUNT_TOKEN_RE` и группировку хвостовых числовых
   токенов в `maib.ts` с реальным форматом строк.

Не коммитьте сюда настоящие выписки с персональными/платёжными данными —
файл добавлен в `.gitignore`.
